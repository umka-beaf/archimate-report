# История изменений

🇬🇧 [English](CHANGELOG.md) · 🇷🇺 Русский

Все значимые изменения проекта фиксируются здесь, по одной секции на версию
проекта (что такое «версия проекта» и как она соотносится с версией Archi в
теге образа — см. [docs/VERSIONING.ru.md](docs/VERSIONING.ru.md)). Этот файл
фиксирует только то, что реально изменилось для того, кто запускает образ,
а не каждый коммит — за такой детализацией см. историю git.

## [1.1.1] — фиксы тёмной темы и релизного пайплайна

Багфикс-релиз, без изменений функциональности.

- Исправлена тёмная тема отчёта: заголовки панелей (дерево модели, вид,
  детали элемента) оставались на светлом фоне Bootstrap, т.к. собственное
  правило Bootstrap `.panel-default>.panel-heading` побивает по
  специфичности однокласовое переопределение независимо от порядка
  подключения стилей; также затемнено поле поиска по дереву в состоянии
  покоя (не только `:focus`) и трек слайдера зума в Firefox — оба были
  скрыты той же проблемой.
- Исправлено определение версии Archi (`docker/Dockerfile` и собственный
  релизный workflow репозитория): конвенция *тега* релиза на archi.io
  меняется от релиза к релизу (точечная, с подчёркиваниями, смешанная, а
  теперь и вовсе без патч-цифры), а старые релизы не хранятся, чтобы на
  них можно было бы ориентироваться — версия теперь берётся из поля
  `name` релиза, а не из тега; для пинованной версии тег ищется по
  совпадению `name` по всему списку релизов, а не угадыванием формы.
- Зафиксирована версия образа Maven для сборки `linux/arm64` на линии
  `3.9.x` (`maven:3.9-eclipse-temurin-21`): плывущий тег `maven:3-eclipse-
  temurin-21` переехал на Maven 3.10.0, чей встроенный Maven Resolver 2.x
  отклоняет классификатор с `/`, который Tycho присваивает system-scope
  зависимостям, инжектируемым из `Bundle-ClassPath` бандла — это сломало
  arm64-сборку из исходников на новом модуле `com.archimatetool.markdown`
  в Archi 5.10.0 ([eclipse-tycho/tycho#6399](https://github.com/eclipse-tycho/tycho/issues/6399),
  на момент этого релиза не исправлено апстримом).
- Caddy теперь отдаёт `Cache-Control: no-cache` для `.css`/`.js`-файлов
  отчёта. Без этого браузер мог сколь угодно долго отдавать закэшированную
  старую версию темы после обновления образа (без явной информации о
  свежести браузер кэширует эвристически по `Last-Modified`, который между
  сборками не меняется) — именно из-за этого фикс тёмной темы выше мог
  выглядеть "не сработавшим" сразу после обновления, пока не произошла
  перезагрузка с обходом кэша.
- Обработчик межфреймовой навигации отчёта (`js/model.js`) теперь
  защищён от нестроковых `postMessage`-сообщений (например, от
  браузерных расширений или самой DevTools) — раньше падал на всём, что
  не было его собственным форматом `"key=id"`.
- Затемнены таблицы связей на страницах элементов/видов (`table-striped`/
  `table-hover`, например таб «Связи»/«Elements») — нечётные строки и
  состояние hover оставались светло-серыми независимо от темы, что
  выглядело как светлые полосы поперёк тёмной таблицы.

## [1.1.0] — поддержка нескольких моделей

**Главное изменение: один инстанс контейнера теперь может раздавать отчёты
сразу по нескольким независимым ArchiMate-моделям**, каждая на своём пути
(`/<slug>/...`), настраивается через индексированные переменные окружения
`MODEL_<N>_*`. Это значимое изменение возможностей, а не багфикс — полное
описание конфигурации в [docs/MULTI_MODEL.ru.md](docs/MULTI_MODEL.ru.md),
схема forward-auth по path, которую это открывает — в
[docs/SECURITY.ru.md](docs/SECURITY.ru.md).

- Добавлена multi-model конфигурация: `MODEL_<N>_SLUG` и per-model
  переменные `GIT_*`/`MODEL_*`/auth, автообнаружение по окружению (не нужно
  поддерживать `MODEL_COUNT`).
- Добавлены per-slug пути отчётов, корневая заглушка-плейсхолдер и страницы
  «ещё не сгенерировано», не раскрывающие список существующих slug'ов
  неавторизованным посетителям.
- Добавлены per-slug вебхук (`/<slug>/webhook`) и статус (`/<slug>/status`)
  — на общем последовательном воркере генерации с per-slug дебаунсом.
- Одномодельная («легаси») конфигурация продолжает работать без изменений,
  если ни одна переменная `MODEL_<N>_SLUG` не задана.

## [1.0.0] — первый релиз

Всё, что было реализовано до поддержки нескольких моделей: клонирование
одиночного `.archimate`-файла или coArchi-репозитория, генерация
HTML-отчёта через Archi CLI, раздача через Caddy, перегенерация по вебхуку
(схемы подписи GitHub/GitLab/generic), RU/EN light/dark тема отчёта
(`USE_MODERN_CSS`), нативная сборка под `linux/arm64` (без эмуляции),
healthcheck, ретраи/таймауты git-операций.
