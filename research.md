Поскольку вам нужен исключительно консольный режим для сборки HTML-отчетов, вам не нужно компилировать весь Archi с нуля. Всё, что делает этот тяжелый Docker-образ — запускает плагин com.archimatetool.commandline.Вы можете запустить этот плагин напрямую на Raspberry Pi «нативно», используя официальную x86_64 Linux-версию Archi, подменив в ней одну библиотеку и добавив эмуляцию.Вот пошаговый рабочий гайд, как заставить консольный Archi работать на Raspberry Pi без ошибок компиляции.Шаг 1. Подготовка системыУбедитесь, что у вас установлена 64-битная операционная система (Raspberry Pi OS 64-bit или Ubuntu ARM64).Установите эмулятор Box64 (он «на лету» транслирует x86_64 инструкции в ARM64):bashsudo apt update
sudo apt install box64 -y
Используйте код с осторожностью.Установите виртуальный графический сервер. Даже в консольном режиме Archi (из-за движка Eclipse) при генерации HTML пытается инициализировать графический контекст, чтобы нарисовать .png картинки для схем:bashsudo apt install xvfb -y
Используйте код с осторожностью.Шаг 2. Скачивание официального Archi для LinuxВместо сборки из исходников скачайте официальный готовый пакет для Linux (x86_64) с сайта ArchiMate или напрямую через консоль:bashwget https://archimatetool.com
tar -xzf Archi-Linux64-5.9.0.tgz
cd Archi
Используйте код с осторожностью.(Замените версию на нужную вам, например, 5.9.0, если она доступна в релизах).Шаг 3. Патч нативной библиотеки (Критический шаг)Главный виновник ошибки exec format error — это файл Archi (бинарный запускатор) и встроенная виртуальная машина Java (JRE), идущая в комплекте. Мы заставим систему использовать родную ARM64 Java, но сам Archi запустим через Box64.Установите родную Java для Raspberry Pi:bashsudo apt install default-jdk -y
Используйте код с осторожностью.Удалите встроенную x86-папку jre, которая идет вместе с Archi:bashrm -rf ./jre
Используйте код с осторожностью.Шаг 4. Запуск генерации HTML-отчетаТеперь мы запускаем Archi через виртуальный фреймбуфер (xvfb-run), эмулятор (box64), указывая путь к вашей родной ARM64 Java.Выполните команду в папке с распакованным Archi:bashxvfb-run box64 ./Archi \
  -vm /usr/lib/jvm/default-java/bin/java \
  -application com.archimatetool.commandline.app \
  -nosplash \
  -consoleLog \
  --loadModel "/absolute/path/to/your/model.archimate" \
  --html.createReport "/absolute/path/to/output_folder"
Используйте код с осторожностью.Как это работает:xvfb-run создает невидимый виртуальный экран, обманывая движок Eclipse.box64 переводит инструкции самого исполняемого файла Archi.Параметр -vm заставляет Archi выполнять весь основной тяжелый Java-код через родную быструю ARM64 Java, установленную в системе, минуя эмуляцию для 95% процессов.
